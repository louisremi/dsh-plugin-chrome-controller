Advanced settings

These controls are for users who understand interaction timing and pointer movement. The defaults are the project's tested baseline. Changing settings may cause websites to treat activity as automated, block it, or show a CAPTCHA. No values guarantee that a website will accept an interaction. Never use these controls to bypass anti-bot checks.

DSH Web connection

For first setup, open DSH Web yourself and choose Settings, then Chrome browser. Copy the DSH Web origin and pairing code shown there.
